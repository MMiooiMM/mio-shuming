# 第三輪外部 UI 評審：數名其妙（只看 v4g／v4h 截圖）

## 1. 三句話結論
- **能不能傳給親友**：勉強可以傳圖卡，網頁本身還不行。圖卡乾淨；網頁的取名結果頁（390）有大約一半高度是「資料來源」的文字牆（約 y≈3590–7270），分析頁的比較表在手機和桌機都被裁切。
- **等級**：AFTER 是 **competent（中上）**。
- **跟 BEFORE 比**：沒有跨級。這輪把「粉紅被亂用」和「上游檔名、路徑外露」清得很乾淨，但結構性的大傷口都在「已知未處理」清單裡，而且這輪多了一個新的語意衝突（第 3 段）。

## 2. 這一輪五件事的驗收

**① 模式分頁改 segmented control：做到了。**
- 390-01 y≈155–220、1280-01 y≈172–240：灰色軌道，選中項白底、磚紅字、有細陰影，未選中項是深灰字配軌道底。BEFORE 是實心紅塊配白框鈕。
- 觀察：這個分頁高約 64–70px（含副標），比標準 segmented 厚重，但因為有副標，可以接受。

**② 切換鈕選中態一律實心磚紅配白字：做到了，但帶出新問題。**
- 用神手動覆寫：390-03 y≈2900（m03_02 右欄）的木、金、水已是實心磚紅配白字，火、土是白底灰框。BEFORE 是粉紅淡底。
- 「?」展開態：390-03 y≈1160「時間校正」右側、1280-03 y≈1100 已是實心紅圓。
- 同頁其他未展開的「?」都是白底灰框圓，兩種狀態分得開。

**③ 名詞說明框改中性米灰：做到了。**
- 390-03 y≈1190–1265、1280-03 y≈1127–1183：米灰底加左側磚紅線，BEFORE 是粉紅底。
- 全站 AFTER 找不到粉紅用在非負面語意。現在粉紅只出現在：凶（外格 9 凶）、忌（生肖 小）、傷用神（王）、忌神（火、土），都屬負面。

**④ 分享卡片、輸出比較卡片統一為外框次要鈕：做到了。**
- 分享卡片：390-03 y≈1078（BEFORE 是小實心鈕）。
- 輸出比較卡片：390-04 y≈2240、1280-04 y≈1645（BEFORE 就已經是外框）。
- 這兩顆現在和「收藏這個名字」「帶入完整分析」同一樣式、同一高度（約 36px）。
- 仍存在的層級差異：「比較勾選的名字」（390-04 y≈928、1280-04 y≈928）是**小尺寸實心鈕**（約 34px、13px 字）。和主按鈕（約 48px）形成兩種實心尺寸，而且這顆比同區的外框次要鈕還小。

**⑤ 資料來源改人話：部分做到。**

## 3. 這一輪造成的新問題或退步
1. **用神覆寫的選中色和五行語意撞色。**
   - 同一張卡裡，上方「喜用」的木、金、水是綠 chip，「忌神」的火、土是粉紅 chip。
   - 往下幾百 px，同樣的木、金、水變成實心磚紅。磚紅和凶、忌同一個色相家族，看起來像「選了三個凶」。

## 4. AFTER 前五大問題（依對印象的傷害排序）

**1. 資料來源文字牆佔半頁（已知未處理）**
- 截圖：390-02 y≈3590–7270（約 3700px，全頁 7482px）；390-03 同樣約 3000px。
- 原則：漸進揭露，參考資料不能和主內容搶版面。
- 修法：
  - 整區包成 `<details>`，預設收合，摘要列寫「資料來源（22 項）」。
  - 展開後每項只留標題＋一行 13px #6B625B 的摘要＋網域連結。
  - 長段原文引用搬到獨立的 /sources 頁。
- 工時：medium。

**2. 送出後結果不在第一屏（已知未處理）**
- 截圖：390-02 結果從 y≈600 開始；390-03 摘要從 y≈805 開始。手機第一屏看到的仍是填過的表單。
- 原則：結果優先。
- 修法：
  - 送出後把表單收成一條 56px 摘要列（「王小明・2024-03-15 10:30・臺北　✎ 修改」），`scrollIntoView` 捲到結果卡。
  - 摘要卡加上 `position: sticky` 的分享入口。
- 工時：medium。

**3. 比較表裁切，桌機也會（已知未處理）**
- 截圖：390-04 y≈2040–2190 第二欄「中性」被切掉；**1280-04 y≈1336「單名固定・不計」在 1280 寬也被切掉**。
- 原則：資料表不能靜默截斷。
- 修法：
  - 手機小於 600px 時，轉成每個名字一張直式卡（網頁可沿用圖卡版式）。
  - 桌機把該儲存格改成「—」加註腳，或表格區放寬到 `max-width: 880px`。
  - 第一欄 `position: sticky; left: 0; background: #fff`。
- 工時：medium。

**4. 標題孤字斷行（已知未處理）**
- 斷行位置：
  - 「候選名比／較」（390-04 y≈1100）
  - 「生肖喜忌（依預／產期）」（390-02 y≈930）
  - 「名一（1 畫）候選／字」（390-02 y≈1930）
  - 「依用神推薦的候／選字」（390-03 y≈3240）
  - 「生肖字根／辰龍」
- 原則：標題是掃讀錨點，斷行等於品質感崩掉。
- 修法：寬度小於 480px 時，標題列改 `flex-direction: column; gap: 4px`；右側說明降到下一行 12px；標題加 `word-break: keep-all`。
- 工時：small。

**5. 選中態磚紅和吉凶語意衝突，「?」展開像警告（本輪新增）**
- 截圖：390-03 y≈2900、y≈1160。
- 原則：語意色（吉綠、凶紅）不能兼做互動狀態色。
- 修法（兩種選一）：
  - 選中態改成深墨色 `#3A322D` 底、`#FFFFFF` 字。
  - 或保留白底，改 `2px solid #8B2E1F` 框、磚紅字、前綴 ✓。
  - 「?」展開態統一改 `#EDE7DF` 底、`#8B2E1F` 字、無外框，不要實心。
- 工時：small。

**次要（未進前五）**
- chip 形狀不一致（已知）：「姓名匹配」「生肖字根」的吉凶標籤是撐滿整列的長條（390-03 y≈2720、4990），摘要區是行內小膠囊。
- 「三才　三才」重複（已知），網頁摘要和兩張圖卡都有。
- 取名結果頂部的裸網址（見第 2 段 ⑤）。
