### 教訓

- 規格裡的「分配表」要用**動作類別**來分（匯出、導覽、破壞性……），不要逐顆按鈕列，否則同類動作會被分到不同層級。
- 「選中態」不可借用任何語意色的淡底。
- 禁用字守衛除了列舉字詞，還要加**類別規則**，例如路徑樣式 `/\b[\w-]+\/[\w-]+\.(md|ts|json|mjs)\b/`、未渲染的 Markdown `/\*\*[^*]+\*\*/`、資料結構欄位名。

我只看了截圖，沒有讀任何程式、文件或上一輪評語。

## 1. 三句話結論

- **能不能傳：** 分析圖卡現在可以放心傳給長輩，網頁也可以傳。但對方點開後，看到的是 1 萬 px 高的長頁，後半頁是一大片資料來源。
- **等級：** 仍是 **competent**，比上一輪更靠近 polished，但沒有跨過去。
- **和 BEFORE 比：** 等級沒有移動。這一輪修的是「色彩語意」和「按鈕層級」這類細節，決定等級的是資訊量、手機排版和結果位置，這三件都還沒動。

## 2. 這一輪三件事的驗收

### (1) 按鈕三級＋radio／checkbox 品牌色：部分做到

做到的部分：

## 3. 這一輪造成的新問題或退步

1. **用神覆寫開關的選中態退步。** BEFORE 是實心綠配白字，開和關一眼分明。AFTER 是淡粉底加磚紅框，對比變弱，而且和「忌／凶」同色系，語意反了。
2. **兩個匯出圖卡鈕層級不一致。** 分享卡片是實心，輸出比較卡片是外框，這是這一輪才產生的。
3. **取名展開面板失去重點。** 候選字全部改成白底灰框，「收藏這個名字」也降成外框，整個展開面板（390-02，約 y≈1950–2290）已經沒有任何強調色。這個面板是取名流程裡唯一的轉換點，現在看起來和上面的五格說明卡同樣平淡。
4. **灰色 chip 本身沒有造成退步。** 網頁上的「中性」灰字灰底可讀，比較圖卡也沒有變得沒精神，反而讓吉／凶更跳出來。

## 4. AFTER 前五大問題（依傷害印象排序）

### 1. 說明與資料來源的文字牆【已知未處理】

- **截圖：** 390-03 全長 10,065 px，約 y≈6400 以後都是資料來源。390-02 全長 7,621 px，約 y≈3600 以後都是資料來源。
- **原則：** 核心內容和參考附錄要分層。現在附錄的高度超過主內容，長輩滑兩下就迷路。
- **修法：**
  - 「資料來源」整塊改成預設收合的 `<details>`，標題寫「資料來源與計算依據（共 21 項）」。
  - 每則名詞解釋限制 3 行，用 `line-clamp:3` 加「展開」。
  - 網址不要整串顯示，改成「來源連結 ↗」。
- **工時：** medium

### 2. 手機斷行與表格裁切【已知未處理；但 1280 的裁切不在已知範圍】

- **截圖：**
  - 標題被擠成兩行：「名一（1 畫）候選／字」「候選名比／較」（390-02、390-04）。
  - 比較表「生肖喜忌」欄在 390 被切掉，只剩「中」字（390-04，約 y≈1540–1690）。
  - **1280-04 第四欄「單名固定・不計」也被切斷**（約 y≈1330）。桌機寬度都會裁切，不只是手機問題。
- **原則：** 內容不能被容器截斷；標題不能被副文擠到斷行。
- **修法：**
  - 區塊標題列在 480px 以下改成 `flex-direction:column; gap:4px`，標題加 `white-space:nowrap`。
  - 比較表在手機上改成每人一張卡；桌機的名字欄設 `min-width:150px`，chip 允許換行，表格外層 `overflow-x:auto`，並加右側漸層陰影提示可以捲動。
- **工時：** medium

### 3. 送出後結果沒有排在最前面【已知未處理】

- **截圖：** 390-02、390-03 按下送出後，表單仍佔首屏約 880px。摘要要到約 y≈820 才開始，取名結果標題在約 y≈600。
- **原則：** 使用者送出後，下一眼應該直接看到答案。
- **修法：**
  - 送出後把表單收成一行摘要，例如「王小明・2024/3/15 10:30・臺北市【修改】」，高約 56px。
  - 用 `scrollIntoView({behavior:'smooth'})` 捲到摘要卡。
- **工時：** medium

### 4. 首屏有兩塊等重的實心磚紅（模式分頁與 CTA）【不在已知清單】

- **截圖：** 所有頁面首屏。390-01 的「我要取名」選中分頁（y≈155–220）和「列出吉筆畫組合」（y≈520–568）是同色、同重量的實心塊。
- **原則：** 一屏只能有一個主角。分頁屬於導覽，不應該和行動按鈕一樣重。
- **修法：** 改成 segmented control。
  - 外框：`background:#ECE8E2; padding:4px; border-radius:12px`。
  - 選中項：`background:#FFF; color:#8B2E1F; box-shadow:0 1px 2px rgba(0,0,0,.08)`。
  - 未選中項：`transparent`，字色 `#6B6560`。
- **工時：** small

### 5. 粉紅語意殘留，加上匯出鈕層級不一致【不在已知清單】

- **截圖：**
  - 390-03 真太陽時說明框（約 y≈1180）。
  - 用神覆寫開關（約 y≈3045）。
  - 分享卡片實心、輸出比較卡片外框。
- **原則：** 一個顏色只代表一種語意；同一類動作用同一層級。
- **修法：**
  - 說明框底色改 `#F3F1EC`，左線保留 `3px #8B2E1F`，或全部改中性灰 `#CFC8BF`。
  - 開關選中態改實心 `#8B2E1F` 配白字，和 radio／checkbox 同一套品牌色。
  - 兩個匯出鈕統一為外框次要鈕。分享是結果頁的附帶動作，不是主任務。
- **工時：** small

另外兩項沒進前五，但要列出：網頁與圖卡的 chip 形狀不一致（已知未處理）；比較圖卡裡王美玲缺少生肖列、王明缺少外格，而且沒有任何標示（屬圖卡版式，已知未處理）。
