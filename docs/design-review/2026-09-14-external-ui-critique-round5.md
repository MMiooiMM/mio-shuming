# 摺疊元件統一這一輪：只看截圖的外部設計評審

## 1. 三句話結論
- **可以分享，但這一輪讓桌機變醜了。** 手機上沒問題；桌機 1280 的 16 列筆畫組合，每一列的最後一顆標籤都掉到第二行、孤零零靠左，看起來像排版壞掉。修改前那張圖裡，前 6 列都排得進一行。
- **目前是 competent。** 配色克制、排版有秩序、文字可信；到不了 polished，因為手機上的區塊標題會從詞中間斷行、有標籤被裁切、按鈕有 5 種以上。
- **新使用者前五秒的印象**：「一個認真、老派、字很多的命理工具」。暖白底加磚紅主按鈕有氣質，但往下捲是一大片同色的綠標籤加小灰字。

## 3. 前五大問題（依傷害印象排序）

**1. 桌機每一列都有一顆落單標籤（這一輪造成的退步）**
- **位置**：1280-light-10，每一列的第二行，例如 y≈110「總7・吉」、y≈185「總11・吉」；完整頁面 1280-02 也一樣。
- **為什麼讀起來差**：標籤群靠右對齊，但最後一顆掉到下一行、靠左貼在標題下方。同一組資料被拆成兩種對齊，16 列重複 16 次，整片看起來鋸齒狀。原因是箭頭多占的寬度把一行擠爆了。
- **修法**：列改成三欄 grid：`grid-template-columns: minmax(180px,auto) 1fr 24px`。標籤欄 `display:flex; flex-wrap:wrap; justify-content:flex-end; gap:6px`，換行時整群一起靠右。更好的做法是拿掉每顆標籤裡重複的「・吉」（見第 5 點），標籤寬度省下約 30%，桌機一行就放得下。
- **工時**：small

**2. 手機上區塊標題從詞中間斷行（系統性問題）**
- **位置**：390-04 y≈1100「候選名比／較」；390-03 y≈5100+243「生肖字根／辰龍」；y≈3400+140「依用神推薦的候／選字」；390-light-11 y≈615「名一（1 畫）候選／字」、y≈700「名二（2 畫）候選／字」。
- **為什麼讀起來差**：標題是主要的定位點，被右側小字擠到斷詞，會直接讀成「沒做手機版」。這是區塊標題共用規則的問題，不是個別文案。
- **修法**：區塊標題列在 ≤480px 時改成 `flex-direction:column; align-items:flex-start; gap:4px`，右側小字掉到標題下方。標題加 `white-space:nowrap`；右側小字 `font-size:12px; color:#7A716A`。
- **工時**：small

**3. 收藏比較表的標籤被裁切、表格橫向捲動沒有提示**
- **位置**：1280-04 y≈1336，王明「單名固定・不…」直接被切掉，桌機就有；390-04 y≈1270–1700，第二欄之後被裁掉，看不出可以左右滑。
- **為什麼讀起來差**：被裁切的文字是最明顯的「壞掉」訊號。這張表又正是會被截圖傳給長輩的畫面。
- **修法**：
  - 表格外包 `overflow-x:auto`，右緣加 24px 漸層遮罩 `linear-gradient(to right, transparent, #FFFFFF)`。
  - 第一欄 `position:sticky; left:0; background:#FFFFFF`。
  - 長標籤允許換行（`white-space:normal; max-width:96px`），或縮寫成「單名固定」，完整說明放註腳。
- **工時**：medium

**4. 展開的內容沒有歸屬感，而且又長出卡片套卡片**
- **位置**：390-light-11 y≈75–975；1280-light-11 y≈85–550。
- **為什麼讀起來差**：這一輪才在資料來源拿掉框中框，但筆畫組合展開後是「面板 → 列 → 五張有框的五格卡片 → 卡片裡的標籤」四層框。展開區跟下一列之間只有一條淡虛線，長度一長，就搞不清楚它屬於哪一列。
- **修法**：
  - 展開區加底色 `#FAF7F2`（深色 `#2A2623`），加 `border-left:2px solid #8B2E1E`，`padding:12px 12px 16px 14px`。
  - 五格卡片拿掉框，改成分隔線列（`border-bottom:1px solid #EDE8E0`），跟這一輪「列不加框」的方向一致。
  - 兩行條列說明（y≈560）目前緊貼卡片、沒有左側內距：補 `margin:12px 0 0; padding-left:20px`。
- **工時**：medium

**5. 一整片綠標籤是雜訊，蓋過了箭頭這個操作提示**
- **位置**：1280-light-10、390-dark-10，整張圖。
- **為什麼讀起來差**：這份列表本來就只列吉的組合，80 顆標籤每顆都寫「・吉」，資訊量是零，視覺重量卻最大。標籤還是實心底色，比 10px 的灰色箭頭顯眼得多，可點的暗示因此被壓下去。
- **修法**：
  - 列表層的標籤拿掉「・吉」，只留「人5／地3／外3／總7」。
  - 標籤改成無底色、`color:#5C6B5E; font-size:12px`，用「·」串接。
  - 箭頭放大到 16px，顏色 `#6E655D`（深色 `#A39A91`）。
  - 換底色加深到 `#F1ECE3`（深色 `#2E2A27`）。
  - 開啟中的列標題保持這個底色，當作「目前打開」的標記。
- **工時**：small

## 4. 一致性稽核

- **卡片／面板底色：5 種。** 白色面板、暖白頁面底、米色輸入框底、米色說明框加紅色左線（1280-03 y≈1130「真太陽時」）、換底色 #F4F2EC。可以接受，但說明框只出現一次，是孤例。
- **按鈕：7 種。** 實心磚紅大按鈕（開始分析）、實心磚紅小按鈕（比較勾選的名字，1280-04 y≈928）、磚紅外框按鈕（分享卡片、帶入完整分析、收藏這個名字）、切換鈕實心或外框（用神的木火土金水，1280-03 y≈1080）、純文字按鈕（移除）、分頁切換（我要取名／分析名字）、候選字的字格按鈕。「比較勾選的名字」的實心小按鈕跟外框按鈕同尺寸卻不同階層，是最亂的一處。
- **說明圖示「?」：2 種。** 實心紅色圓（1280-03 y≈1100 時間校正），和灰色外框圓（其他所有地方）。
- **標籤形狀：4 種。** 圓角膠囊（吉凶）、撐滿整行的長條（生肖字根的「喜／忌」、姓名匹配的「傷用神・土」，1280-03 y≈350、y≈1283）、方角字格（候選字）、五行計數方塊（1280-03 y≈840）。長條版本最突兀：一個字的標籤卻撐滿 490px。
- **圓角級距：約 4 級。** 面板約 12px、內卡約 8px、按鈕約 6–8px、膠囊全圓。還算一致。
- **字級階層：約 7 級。** 字標 28px、區塊標題 17px、列標題 15px、內文 14px、說明文字 12px、標籤 11px、五格數字 18px 加五行字。說明文字和標籤太接近，而且灰度不一。
- **摺疊元件：2 種。** 分隔線列（筆畫組合），和獨立卡片列（資料來源）。忌字連結沒截到，無從計數。

**像幾隻手做的？** 大約 2.5 隻手。配色和字體是一個人的；分析頁中段（用神、姓名匹配、生肖字根的長條標籤、候選字範圍輸入框）像另一個人的；比較表的按鈕像第三個人補上去的。

## 5. 真正有效、改版時要保護的
- **暖白底加磚紅主色。** 在命理類型裡少見地克制，長輩看不俗氣，年輕人看不土。
- **資料來源單層卡片加 390-light-13 的聚焦外框。** 外框顏色、粗細、圓角全對。這是這一輪做得最乾淨的一處，其他元件的聚焦狀態照抄它。
- **五格卡片的資訊結構**：格名、數字加五行、算式、判定膠囊（1280-03 y≈1040–1490）。一眼可以掃完，吉凶用色節制。
- **比較表頂端和摘要頁「各項獨立判定、不計數、不加總」的誠實說明。** 這是可信度來源，不要為了簡潔拿掉。
- **分頁切換**（首頁 y≈170–240）：選中的是白色浮起的膠囊，狀態一眼清楚。

### 複查新提出的問題與處置

- **A（高）hover 與 focus 同樣是紅框，滑鼠點擊也會出現**：**不成立，是截圖腳本造成的**。腳本先用 Tab 聚焦再 hover，同一張圖同時有兩種狀態。實測（Chromium）：
  - 滑鼠點擊後 `:focus-visible=false`、`outline: none`，只有 hover 底色。
  - 鍵盤 Tab 後 `:focus-visible=true`、`outline: solid`。
  - 只 hover 時沒有外框。
- **B（中）觸控裝置 hover 底色黏住**：**成立，已修**。hover 樣式包進 `@media (hover: hover)`。模擬觸控裝置點擊後，底色是透明。
- **C 手機列高參差（3/16 列 103px）、D 候選字標題斷字、E 展開區內距、F 忌字說明重複括號、G 忌字開關字重偏弱**：本輪不做，列為下一輪候選。其中 C、D 與第五輪第 2、5 點同源。
