數名其妙 v2

八字排盤 ・ 用神判定 ・ 姓名匹配

2026-08-10 已凍結

由 /mio-hot-sauce grill 收斂。本檔為 v2 開發、驗證與獨立 review 的凍結判準。

範圍

  1. 完整鏈：八字排盤 → 用神判定 → 姓名匹配（含候選字推薦）。三段都要有，缺一不算完成。
  2. 不做大運、流年、納音、神煞。用神只依本命四柱，不隨時間變動。

輸入

  1. 在 v1 的姓／名／西元年月日之外，新增出生時間（時＋分，必填）與出生地（台灣 22 縣市下拉，另備手填經度＋時區給海外出生者）。
  2. 缺出生時間時不產出八字，僅提供 v1 的姓名分析，並明確說明原因。
  3. 年份範圍沿用 v1 的 1900–2100。

時間校正

依序套用，且每一層都要能在畫面上看到。

  1. 夏令時間：命中查證過的台灣實施年份時自動減 1 小時，並在畫面明示「已自動校正」。手填經度的海外出生者退回手動勾選。
  2. 經度差：依出生地經度與時區標準經線之差校正（每度 4 分鐘）。
  3. 均時差：依出生日期計算真太陽時與平太陽時之差（±16 分內）。
  4. 畫面需呈現「輸入時鐘時間 → 校正後真太陽時」的對照，讓使用者看得出動了多少。
三層加起來可達 ±20 分鐘，而時辰邊界正是這個量級——這是八字軟體最常見的錯誤來源。

排盤

  1. 輸出四柱（年月日時的天干地支）、藏干、十神、五行分佈。
  2. 月柱依節（每 30° 黃經）換柱，非農曆月；年柱依立春換柱，與 v1 生肖判定一致。
  3. 早晚子時：預設 23:00 換日柱；出生於 23:00–23:59 者明確標示另一派會得到不同日柱，並提供一鍵切換重算。

用神

  1. 演算法採扶抑為主 ＋ 調候修正 ＋ 從格例外偵測。
  2. 必須逐項攤開判斷依據：得令／得地／得勢、日主強弱結論、調候需求、是否觸發從格。
  3. 使用者可手動覆寫用神並重算匹配。
  4. 用神給喜用／忌神的分項判定，不給分數。

姓名匹配

  1. 匹配尺度用字形五行（康熙部首）；v1 的數理五行（筆畫尾數）留在五格區不變，兩者不混用，且畫面要說明兩把尺各自量什麼。
  2. 逐字評述：哪個字補到用神、哪個字傷了用神、哪個字中性。
  3. 依用神推薦候選字，以查證過的常用字表過濾，避免列出冷僻字。

貫穿全案的原則（沿用 v1）

  1. 不合成單一總分——八字、五格、生肖、匹配各自分項判定。
  2. 每條規則的出處寫在資料檔的 source 欄位，並在「資料來源」區塊呈現。
  3. 流派衝突不擅自調和：選邊後在資料檔標明衝突與未採用的另一派。
  4. 引擎維持純函式——不讀當下時間、不讀隨機數。
  5. 罕字、資料範圍外、無法判定的情況一律明確回報，不猜。
  6. 授權維持 GPLv2。

實作前必須查證的清單

  1. 不得憑印象寫，逐項走 /mio-istj 查權威來源並在資料檔註明出處：
    • 台灣夏令時間實施年份
    • 214 部首 → 五行 對照表
    • 十二節的黃經度數與節名
    • 日柱干支的紀日錨點
    • 五鼠遁（日干 → 時柱天干）與五虎遁（年干 → 月柱天干）
    • 十神定義表
    • 扶抑／調候／從格的具體判準與權重
    • 常用字表（候選字過濾用）

已知風險

第 13、14 項是本清單唯一無法靠對照權威資料驗收的部分——扶抑與調候的權重各家不同，最終仍是選邊。驗收方式只能是與指定的某一本書／某一站的範例命盤逐例對照，實作時要先選定對照基準並記錄在資料檔。

可重用的既有資產

  • tools/gen-lichun.mjs 的太陽視黃經解法可直接推廣：目標黃經從 315°（立春）改成十二個節（每 30°）即得月柱換柱表；均時差也用同一套機制算，不必另找資料表。
  • src/data/components.json 生成時已算出每字的康熙部首，字形五行只差一張 214 部首 → 五行 對照表。
  • src/data/kangxi-strokes.json 涵蓋 BMP 27,584 字的筆畫，候選字推薦可直接用。
  • NameInput.birth 是既有擴充點；analyse() 目前純函式不讀時鐘，擴充不會動到既有五格與生肖路徑。
